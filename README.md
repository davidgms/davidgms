## About

Seven years building and modernizing web platforms, from legacy PHP monoliths to decoupled Vue and React front-ends talking to REST APIs.

Currently at **CCONET**, working across React 19, Node.js and Laravel on a public safety SaaS used by municipal guard, civil defense and traffic departments in several Brazilian cities. Incident lifecycle from dispatch to closure, patrol operations, fleet, armory, live camera monitoring.

Outside work I am writing a **Game Boy Advance emulator in Rust**, which is the most fun I have had being bad at something in years.

I also run agentic AI in my daily workflow: multi-agent orchestration with Claude Code and OpenCode, MCP servers wired into projects, and local models through Ollama. I care about token cost the way I care about bundle size.
